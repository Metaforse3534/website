Security & Integrity.

Security covers account security, data security (encryption in transit; appropriate controls at rest), infrastructure practices, and AI system integrity.

Cryptographic Isolation

Data encrypted in transit via TLS 1.3 and at rest with AES-256 GCM. User workspaces run in isolated execution enclaves.

Zero Model Training

Customer source code, uploaded documents, prompts, and workspace state are never retained for general model training.

GDPR & DPA Readiness

Headquartered in the Netherlands, operating strictly within European data protection standards with full DPA execution.

Responsible Disclosure Policy
